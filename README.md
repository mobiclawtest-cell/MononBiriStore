# মনন বিড়ি - অফিশিয়াল ওয়েবসাইট (GitHub Pages Ready)

১০০% খাঁটি ও বাছাইকৃত উন্নতমানের তামাক পাতায় প্রস্তুত মনন বিড়ির অফিশিয়াল ই-কমার্স ও তথ্যচিত্র ওয়েব প্ল্যাটফর্ম।

এই রিপোজিটরিটি সম্পূর্ণ **স্ট্যান্ডঅ্যালোন ও স্ট্যাটিক (Pure Static Vanilla HTML/CSS/JS)**। কোনো বিল্ড স্টেপ বা জটিল কনফিগারেশন ছাড়াই সরাসরি **GitHub Pages**-এ চালু করার জন্য প্রস্তুত।

---

## 🚀 গিটহাবে লাইভ ওয়েবসাইট চালু করার সহজ নিয়মাবলী (How to Enable GitHub Pages):

আপনি রিপোজিটরিতে কোড পুশ করার পর ওয়েবসাইটটি সরাসরি লাইভ করার জন্য নিচের ২টি পদ্ধতির যেকোনো একটি ব্যবহার করতে পারেন:

### পদ্ধতি ১: সাধারণ গিটহাব পেজেস সেটিংস (সবচেয়ে সহজ - ১ মিনিট)
1. আপনার গিটহাব রিপোজিটরির পেজে যান।
2. উপরের মেনু থেকে **Settings** ট্যাবে ক্লিক করুন।
3. বাম পাশের মেনু থেকে **Pages** অপশনটিতে ক্লিক করুন।
4. **Build and deployment** সেকশনের নিচে:
   - **Source**: নির্বাচন করুন **"Deploy from a branch"**
   - **Branch**: নির্বাচন করুন **`main`** (অথবা `master`) এবং ফোল্ডার হিসেবে **`/ (root)`** রাখুন।
5. **Save** বাটনে ক্লিক করুন।
6. ১-২ মিনিটের মধ্যে পেজটি রিলোড করলেই উপরে আপনার লাইভ ওয়েবসাইটের লিংক দেখতে পাবেন:
   👉 `https://<your-username>.github.io/<repository-name>/`

---

### পদ্ধতি ২: অটোমেটিক গিটহাব অ্যাকশনস (Automated Workflow)
এই রিপোজিটরিতে ইতিমধ্যে `.github/workflows/deploy.yml` যুক্ত করা রয়েছে:
1. রিপোজিটরির **Settings** -> **Pages**-এ যান।
2. **Source** ড্রপডাউনে **"GitHub Actions"** নির্বাচন করুন।
3. এখন থেকে প্রতিবার `git push` করলেই স্বয়ংক্রিয়ভাবে ওয়েবসাইট আপডেট হয়ে যাবে!

---

## 📁 প্রজেক্ট স্ট্রাকচার:
- `index.html`: মূল ওয়েবসাইট (ইনলাইন স্টাইলিং ও জাভাস্ক্রিপ্ট ইঞ্জিন)
- `404.html`: গিটহাব পেজেস রিডাইরেক্ট সাপোর্ট
- `.nojekyll`: গিটহাব পেজেস স্ট্যাটিক ফাইল প্রসেসিং এনাবলার
- `images/`: পণ্যের বাস্তবসম্মত ৪-কোণের ছবি ও আইনস্টাইন ঐতিহাসিক ব্যানার
- `.github/workflows/deploy.yml`: অটো-ডিপ্লয়মেন্ট অ্যাকশন
